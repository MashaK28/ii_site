# Душевные вопросы

Одностраничный генератор вопросов для друзей — чтобы начать разговор, узнать друг друга ближе или обсудить то, на что в повседневности не всегда хватает времени.

**Публичная версия:** [mashak28.github.io/ii_site](https://mashak28.github.io/ii_site/)

> Сайт публикуется через GitHub Actions. Если ссылка ещё не открывается, дождитесь первого успешного запуска workflow **Deploy to GitHub Pages** во вкладке **Actions** репозитория.

## Как пользоваться

1. Откройте [сайт «Душевные вопросы»](https://mashak28.github.io/ii_site/).
2. Выберите настроение: **Все**, **Лёгкие**, **Глубокие** или **Для знакомства**.
3. Нажмите **«Следующий вопрос →»** — карточка покажет случайный вопрос из выбранной категории.
4. Обсуждайте вопрос в комфортном темпе. Счётчик отмечает каждое нажатие.

В подборке 54 вопроса. Один и тот же вопрос не выпадет дважды подряд, если в выбранной категории есть другие варианты.

## Локальный запуск

Приложение не требует сборки, установки пакетов или сервера.

**Прямое открытие:** скачайте или клонируйте репозиторий и откройте `index.html` в браузере.

**VS Code Live Server:** откройте папку проекта в VS Code, установите расширение Live Server, нажмите правой кнопкой на `index.html` и выберите **Open with Live Server**.

## Технологии

- GitHub Actions и GitHub Pages для публикации.

## Публикация

Workflow `.github/workflows/deploy.yml` запускается при каждом push в `main`, а также вручную из вкладки **Actions**. Он загружает файлы проекта как артефакт Pages и публикует сайт. Для первой публикации в настройках репозитория **Settings → Pages** в качестве источника должен быть выбран **GitHub Actions**. Адрес проекта: `https://mashak28.github.io/ii_site/`.
